## 1. 评论（visitor UGC · 独立存储）

**要做，但不要现在做。** 全仓尚无 comment；加评论 = 第三条写轨（现有：HTTP Bearer、owner session），且 **UGC 以服务器为真相**——档案正文同样以服务器为真相（[0021](adr/0021-server-content-authority.md)），但评论仍不得进 `content/`。

### 形状（开刀时一次锁死）

| 面 | 决定 |
|----|------|
| 存储 | gitignore 的 `data/comments/`（类比 [0011](adr/0011-music-local-cache-public.md)），**绝不进** `content/`，不进 publish 白名单 |
| 关联 | 按 `DocumentRef` / localKey 挂 `projects/*`、`thoughts/*`；`open` 后阅读面板底部列出；终端可加 `comment`（help 可见） |
| 身份 | **不登录、不绑定账号**。可选昵称（cookie / localStorage）+ IP 限流（对齐 owner login）+ 字数上限 + **纯文本**（0007 href 白名单，禁 HTML） |
| 管理 | owner 可删；无公开编辑他人评论 |

### 必开 ADR

visitor 可写直接撞 [0007](adr/0007-security-deployment-posture.md) 纪律 B/C。评论**不是** `content-write.ts` 四操作，不能假装档案写。

### 明确不做

强制账号、评论进 Git、评论当第二套档案正文、上线前反垃圾全家桶、公开注册当评论身份。

## 2. member · 邀请制（不是注册系统）

**公开注册：否决**（[0010](adr/0010-site-principal.md) Rejected）。评论者 ≠ member。

| 概念 | 含义 | 现状 |
|------|------|------|
| **member**（能力格） | 可读 `content/private/`，默认不可写 | [0019](adr/0019-capability-zone-permission.md) 裁剪已支持；`MEMBER_GRANT` 已有 |
| **member 登录** | 把浏览器会话解析成 member actor | **未实现**；须**新 ADR**，不偷渡改 0010 |
| **公开注册** | 自助 signup | **不做** |

正确形状：owner **邀请**（签发会话 / 一次性口令），不是开放 signup。没有「要把私文给谁看」的故事前不开。

与评论分流：留名用可选昵称；读私文才升级 Principal。

## 3. UI 动效 / 体验（上线后对着真机）

**不挡上线；现在不重设计。**

已有且应对齐的层：

- 动效 token：`lib/archive/motion-spec.ts` + `prefers-reduced-motion`
- CSS：`app/styles/`（production / lab / workspace / terminal / reading / editor / bgm）
- 外区禁区：[`04`](04-外区设计读法.md)

上线后可抽的小刀（仍非第二套主题）：窄屏 BGM 两行或沉入背景、阅读全屏、面板开合手感、lab 色板是否还留在生产构建。不要再加第 6 套主题。重设计应在有真实观感之后（[`19`](19-现实校验与执行序列.md) §4.6）。

## 4. 双轨：代码 Git · 正文在服务器

权威见 [0021](adr/0021-server-content-authority.md)。此处只留指针。

| 层 | 谁管 | 本机 | 远程（生产） |
|----|------|------|----------------|
| **代码** | Git | 工作副本 | `git pull` 后的运行副本 |
| **档案正文** | 生产 `content/` | 上传快捷方式（不是镜像） | **权威**（含 private） |
| **曲库 `data/music/`** | 生产盘 | 不推、不改 | 远程 download / sync |

运维入口仍在 **D:\VPS\my_web**（非 npm）。控制台按 0021：只上传（含 private）、无 `--delete`、备份从远程打包。密钥主人自持。不做双向自动同步、不做日常拉全量。

## 5. 浏览模式（藏终端 + 简单导航）

**方向对；形状要对；时机在正文之后。**

与否决的关系：[`06`](06-v1.0-路线纲要.md) / [`09`](09-v1.x-后续工作.md) / [`19`](19-现实校验与执行序列.md) 否决的是「第二套非终端首页 / 进场动画」。本文允许更轻的出口：

| 做 | 不做 |
|----|------|
| 同一 `app/page.tsx` / 同一 snapshot / 同一 `ReadingSurface` | 另一套博客视觉、作品网格、英雄区、新色板 |
| `browse \| terminal` 切换（boot 可默认 browse） | 拆成独立站点或平行 IA |
| 导航列 `projects` / `thoughts` / about；点击 = 现有 `open` → reading-panel | 为浏览模式重做排版引擎 |

前置：**至少一篇值得读完的中文长文**。空卡片做成博客首页，比神秘终端更糟。

## 6. 建议抽刀顺序（开门之后）

1. 有可读长文 + 访客不会 `open` → **§5 浏览模式**

3. 真机刺眼 → **§3 体验小刀**
4. 有 private 要给具体的人 → **§2 member 邀请**（新 ADR）
