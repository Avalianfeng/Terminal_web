## 0. 这篇在反对什么

8 月 13 日那次评估（以及 `09` 的债分级）是对的——在「不要一哄而上」的阶段。它把下一刀收成：写一篇长文、上线先做闸门、music 离开主线。

那套收束已经完成了它的工作：闸门、身份、本地曲库、终端排放首刀都在两天里落地。继续用同一把尺子，只会再抽出「download 进度条 / 档案命令 sweep / 再写一篇 stub」。

**现在缺的不是更小的刀，而是把「这是什么地方」设计完。**  
cylf.me 不是功能清单的并集，而是一个人的数字档案被进入的方式：终端是探索语言，纸面是阅读场，HTTP 是给 Agent 的门。下面的方向按这个整体写，不按「这周能合什么」。

## 1. 此刻的系统是什么

最小 v1.0 的机器面（A–E）在 8 月上旬已经闭环。8 月 15 日又补上了**公网作为两种存在**和**音乐作为可公开的气候**：

| 层 | 现在实际是 |
|----|------------|
| 身份 | `SitePrincipal`：visitor / owner；公网 `login` 会话；local-dev implicit owner（[0010](adr/0010-site-principal.md)） |
| 写 | HTTP 仍 Bearer；UI 写认 owner；Actions 硬拒 visitor；事故闸 `ARCHIVE_UI_WRITE=false` |
| 呈现安全 | prose `href` 白名单；写 API CORS 分策略；runbook [`13`](13-cylf.me-部署.md) |
| 音乐 | 主人：网易 BFF + download；访客：只见「本地」曲库、只播 `data/music/`（[0011](adr/0011-music-local-cache-public.md)） |
| 终端语言 | 排放契约已立（[0012](adr/0012-cli-output-contract.md)）；music 首刀进 `cli-emit`；档案命令尚未 sweep；字节流进度未做 |
| 档案正文 | 几乎未动：13 篇 document，多为 12–25 行状态卡 |

一句话：**壳、闸、气候层已经像一个将要公开的地方；档案里的人还几乎不在场。**

实例尚未部署。代码上已经可以上 cylf.me；产品上还没有「值得进入」的房间。

## 3. 未完成的形状（不是债清单）

这些不是「有空再修的项」，而是系统还缺的**面**。每一面都可以单独做成一轮认真的设计，而不是补丁。

1. **人还不是对象。** 产品句以 Person 为最高对象；实现里人物是 JSON 名片，项目是 WIP 卡，思想是一篇英文蓝图，时间线是四条建站日志。`personal_archive` 里真正的认识工作没有被这个站读出来。
2. **地方还没有门槛与气候的完成态。** visitor/owner 已经是两种权限，还不是两种**在场**：提示符、可发之声、可打开的抽屉、第一次 `help` 看见的世界，几乎同一套壳。
3. **终端还不是一种写完的语言。** 0012 立了体裁（usage/result/error/status），music 先用。`ls`/`open`/`search`/`edit` 仍是另一套嗓子。探索器的文学性只开了头。
4. **纸面还不是世界。** Dual Phase 的空间对了，排版引擎仍是轻量 markdown（无图、表、脚注、文集、阅读路径）。「愿意把一篇读完」缺少一篇，也缺少**配得上长文的纸**。
5. **发现层还是一张表。** Item 模型为外源与多 kind 留了位，但没有关系、没有时间、没有「这篇如何指向那篇」。Agent 能拉到文件，不能进入一个知识结构。
6. **工作场仍是一个上帝组件。** 终端会话、阅读机、编辑器、BGM、身份副作用挤在 `archive-terminal`。空间分层在 CSS 里成立，在模块上还没有。

## 4. 前进方向

下面每一节都是**可以认真设计、值得花时间**的系统面。不是执行顺序。不必一轮做完；但设计时按完成态想，不要按「先做最小切片」。

### 4.1 人物：把主语做实

目标：打开站点时，进入的是**策月帘风**，不是「一个终端壳的自我介绍」。

可做的设计（完整想，而不是先做 JSON 加字段）：

- **Person 作为可读表面**：`open person` / `about` 不再是终端里几行键值。人物有纸面：一段当下的自我陈述、当前焦点的上下文、对外链的编辑意图，而不是 `links[]` 清单。
- **人物随时间叠**：`created` 不够。需要「此刻的人」与「曾经的记录」可并存——档案版本、焦点变迁、自己改正自己。这正是 `personal_archive` 已经在想的 Frame / Moment；公开站可以是那套认识论的**阅读契约**，不必把题库搬进来。
- **附着物有重量**：projects / thoughts / resources / timeline / 本地曲库都是人物的侧面，不是平行频道。列表命令可以按「这个人的工作 / 这个人的想 / 这个人的收藏 / 这个人的日子」读，而不是按文件夹名。
- **中文为主路径**：思想与时间线现在英/中混杂。公开档案的语言是一种立场，值得单独设计，而不是「哪篇先写用哪门」。

花时间的意义：没有这一面，其它面都是空房间的装修。

### 4.2 空间：把 Dual Phase 做成可居住的房间

`04` 的禁区仍然有效（不要英雄区、不要第二套手机 App、不要从终端涌出）。完美主义在这里不是加特效，而是把**已经选对的空间**做满。

- **阅览室的完成态**：主槽是摊开的一份；rail 是桌上其它打开的文件夹（现在像标签条）。可以设计厚度、叠放、回到某份的记忆，而不做窗管。
- **终端高度稳定、阅读随页面生长**——这条已经对。下一步是：长文阅读时纸面是否配得上「坐下来」：行宽、夜读、仅纸全宽、与 BGM 歌词谁让谁。
- **窄屏作为第一公民，而不是压缩桌面。** 现在 ≤640px 把 BGM 播控+歌词+列表塞进一行，等于宣布手机访客不是客人。完成态可以是：终端仍在、纸仍在、气候条改成两行或可完全沉入背景；不是另做一套 IA。
- **全屏的两种**：壳全屏（已有）与**阅读全屏**（纸面暂时成为唯一主语）。后者让长文真正发生。
- **工作场模块化**：按 `01` 的 A/B/C 层拆组件与状态（阅读会话已经纯；BGM/身份仍绑在终端主机）。这是空间能继续被设计的前提。

### 4.3 终端：把探索做成一种语言

0012 是目前最接近「不吝啬手艺」的刀——它把 xterm 当出版物的排版，而不是 log dump。完成态远大于 music sweep。

- **一种方言，不是两套嗓子。** `ls` 的 POSIX 骨架 + 中文宾语，推广到全部档案命令。`open`/`search`/`find`/`edit`/`timeline` 的成功必须点名对象；错误给下一句可执行命令。访客在终端里感到的，是这个档案自己的口音。
- **进度与确认作为仪式。** download 的 wget 式单行、`[y/N]: y` 同行——已经开始像真 CLI。长操作（sync、import、批量 open）都配得上同样的仪式感。
- **帮助是地图，不是百科。** `help` 可以指向「今晚建议打开的一份」；子命令缺参只出该子命令 usage（0012 已定）。boot 不必做 whoami 剧本，但第一次进入可以有**一句属于这个地方的话**——仍是终端体裁，不是落地页。
- **补全即探索。** Tab 已经能走路径与 music。完成态：补全结果本身可读（标题、状态、一句摘要），像在目录卡片上移动手指。
- **xterm 的可达性不必假装已支持，但要给退路。** 跳过终端、直接进入当前推荐纸面；读屏至少能抓住阅读区。这是把「终端第一」设计完整，不是放弃它。

### 4.4 纸面：让长文配得上被打开

`06` 对人的承诺是「长文与世界观材料要在站内有好的呈现，而不是 markdown 预览凑合看」。引擎还停在预览。

值得设计的排版世界（仍守 Dual Phase：纸是纸，不跟终端抢酷）：

- 图与图注、表、脚注、题辞、引用层级、诗行、对话体
- 文集 / 系列：一组 thought 作为一本书，而不是平铺 slug
- 阅读路径：一份「推荐阅读」本身是档案对象（可 `open`、可被 Agent 拉），不是 boot 里的硬编码字符串
- resources 三区从 demo 变成真正的收藏墙：一篇外文配一段自己的话，视频/音频作为**被解读的对象**，不是 embed 能力展示
- 标题语义与 DOM 对齐（`#` 不要落到随便一级）——这是排版尊严，不是 a11y 边角

内容策略配得上这个纸面：从 `personal_archive` 公开摘出可读正文；projects 从 WIP 卡长成**可被后人打开的记录**（过程、判断、失败），不是状态摘要。允许一篇写很久。

### 4.5 时间：让档案会老

现在的 timeline 是站点建设日志。人物档案的时间应当是：

- 条目有 `created` / `updated`（`09` 把它当成能力债；作为系统，它是**人还活着的证据**）
- 同一份文件可以看见自己被改过（hash 已有；缺的是对访客可读的变迁，而不是 Git 责备）
- 时间线能混入打开过的思想与项目，而不是一个孤立 markdown
- 「当前焦点」会过期，过期后仍留在场——这是 Person 的时间性，不是 frontmatter 里一行字

### 4.6 音乐：作为房间的气候，而不是播放器产品

0011 已经决定：访客可以听见主人选过、落过盘的歌。这就不再是「本机附属」那么简单。

完成态不是网易云，而是：

- **「本地」歌单是礼物。** 访客听到的是被挑选过的气候，不是 yaml 全量的残缺投影。挑选、排序、是否公开某一首，配得上和 thought 一样认真的策展——即使 UI 仍只有终端 + 底栏。
- **正在读的和正在响的可以相关。** 不必做「文内配乐」产品；可以做很轻的档案挂钩：某篇 thought 注明写作时在听的歌，打开时气候可应、可不应。关系在档案里，不在推荐算法里。
- **底栏是气候条，不是第三套主语。** 歌词可以像纸面的旁注；窄屏必须能把气候沉下去。暂停时不要空转（rAF）。音量、session 恢复、字节流进度——都是手艺，不是功能点。
- **路线句必须承认它。** 改 `06`/`09`：公网气候层（已落盘子集）是档案的一部分；网易替代、管理页、图库首页化仍然否决。

### 4.7 身份：两种在场，而不只是两道闸

0010 解决了「谁能改盘」。还没设计「作为访客走进去」和「作为主人坐下来」有什么不同。

可以很深、仍然不做登录页 / OAuth / 第三人：

- **门槛：** `login` 保持秘密命令是对的（不在 help 里教）。完成态可以是提示符或壳的极小变化——主人回家了，灯的色温不同——而不是仪表盘。
- **访客的尊严：** 不要灰条、不要「登录后解锁 122 首」。访客看见的世界应当自洽：能读的文章、能听的气候、能走的命令，全部够用。缺的能力沉默，不乞求。
- **主人的书桌：** edit、download、sync 是同一双手。排放契约已经开始让这些动作像在自己的工作室里说话。
- **部署是开门。** runbook 已有；缺的是真的让 cylf.me 成为一个有气候、有一篇长文、有主人偶可回来的地址。开门本身是产品完成态的一部分。

### 4.8 发现层：从表到图

`08` 的 Item 是正确的最小形状。完美主义的下一步不是急着加 `kind: music`，而是让**已有的 document 互相成为入口**：

- 正文里的站内链是一等关系（`open` 得到的纸面可以指出下一份）
- 索引暴露时间、系列、人物侧面；Agent 可以按图走，不必先发明全文检索
- 外源（GitHub 等）在图稳定、本地正文配得上之后再挂——身份模型已经为它留了位，缺的是「本地已经是一个世界」
- HTTP 检索 / 分页在图与正文规模起来之后自然成为需要；现在做是空类型

### 4.9 Agent：正式的访客，不是爬虫

写闭环已经比多数个人站认真。完成态是：**Agent 能像懂规矩的客人一样使用这个地方。**

- 发现文档写得像门厅说明（`08` 已接近）；缺一篇「推荐阅读路径」的机器可读对象
- 写 thoughts 的 Agent 工作流被真的用起来——否则鉴权写只是能力展示
- 终端方言与 HTTP 信封是同一档案的两种语言，不要求 Agent 模拟 shell
- 审计、webhook、多人 session 仍然是以后的建筑；先把「一个主人 + 一些 Agent + 许多访客」住熟

### 4.10 站点作为地方（cylf.me）

部署不是运维收尾，是这个系统第一次面对陌生人。

值得单独设计的「地方性」：

- 第一次打开：终端 boot 的那几行就是门牌。现在是通用「档案壳已启动」。可以写成这个人的房子会说的话。
- 回来的人：不必做账号。气候、焦点、时间线会变，已经是「还活着」。
- 域名、口令、曲库 volume、网易 Cookie 在部署机上的存在——`13` 已列。完成态是跑过一次，并接受公网与本机的差异（访客无 BFF、气候更短）。

### 4.11 工程手艺（配得上上面那些面）

不是「补测试套件」愿望单，而是让结构撑住设计：

- **正文懒加载**：snapshot 只下索引，`open` 再取篇。这是长文世界的地基，不是性能边角。
- **0012 sweep**：档案命令进同一 emitter；download 进度做成契约里已经画过的那一行。
- **CI**：lint / tsc / 现有 `tsx` 单测 / smoke 挂上 PR。edit 仍可靠 [`11`](11-终端edit手测清单.md)，但内核回归不应靠自觉。
- **adr 索引自洽**：0007 行仍写闸门未落地——地图的尊严。
- **上帝组件拆除**：BGM 会话、身份、阅读、xterm 分家。否则 4.2 / 4.6 的空间设计会一直撞墙。

## 5. 设计行为（可以开的专题，不是勾选顺序）

每一条都配得上一次真正的设计（约束、否决、完成态），而不是「顺手改」。

| 专题 | 完成态长什么样 | 已有锚点 |
|------|----------------|----------|
| 人物纸面 | `open person` 是一篇人，不是字段表 | `person.json`、`about`/`whoami` |
| 公开长文 | 至少一个可坐下来读完的中文世界；最好是一个系列 | `thoughts/`、`personal_archive` |
| 阅读路径对象 | 可 `open`、可被 Agent 拉的「从哪读起」 | boot / `help`（勿做成剧本页） |
| 纸面排版引擎 | 图注/脚注/文集仍是纸，不是卡片秀 | `markdown-prose`、`04` |
| 气候条 | 窄屏可沉；与纸面谁让谁有规定；暂停不空转 | `bgm-bar`、0011 |
| 本地曲库策展 | 访客听到的是选过的礼物 | 「本地」歌单、`data/music/` |
| 终端方言 | 全部命令一种排放；补全可读 | 0012、`cli-emit` |
| 两种在场 | visitor 世界自洽；owner 回家可感 | 0010 |
| 发现图 | 篇与篇的关系进模型或至少进正文约定 | `08`、站内链 |
| 开门 | cylf.me 真的在，且有一篇与一季气候 | [`13`](13-cylf.me-部署.md) |
| 索引与正文分离 | 加厚后首屏仍轻 | `ArchiveSnapshot` |
| 工作场拆分 | A/B/C 层在代码里也分层 | `01`、`archive-terminal` |

这些可以并行构思，**不要**再收成「先做最小的那一个」。若必须选一个开口：人物 + 一篇真长文，会点亮最多其它面；若必须选一个手艺开口：终端方言 sweep + 纸面排版，会让已有壳配得上那篇长文。两者都值得花时间，都不是 09 意义上的「债」。

## 6. 完美主义也不该翻案的

认真设计和「把否决项重开」不是一回事。下列完成态**仍然不要做**——它们会把这个地方变成别的站点：

- 第二套非终端首页、进场动画大片、作品集英雄区
- 完整网易云替代、冷库管理页、3D 歌单架、图库首页
- 站内 AI 聊天 / 多文推理产品（Agent 走 HTTP，人走纸面）
- 无鉴权写、把写 token 贴进浏览器、第三人账号
- 外区组件库特效、生产色板超市、真窗管
- 为了发现层「完整」而空枚举 `kind: image|music|video`

`04` 的禁区、0009 对管理页的否决、0010 对登录页的否决，继续有效。完美主义用在**把已选的形状做满**，不是推翻形状。
