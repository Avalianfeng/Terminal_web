## 3. v1.x 工程债（有需要再开）

| 项 | 说明 | 建议时机 |
|----|------|----------|
| HTTP 全文 / 路径检索 | 终端有 `search`/`find`，HTTP 无等价 | Agent 扫读不够用时 |
| 终端 `edit` 接 `expectedHash` | 与 HTTP If-Match 对齐；本机单用户可暂缓 | 人机同改同一文件时 |
| 写后客户端自动 refresh | 已有 `revalidatePath`；已打开阅读面板仍可能陈旧 | 同页 Agent+人并发时 |
| 完整权限 / 审计 / session | 超最小 Bearer+scope | 多人 / 生产加固时 |
| 写后触发（webhook / 重建） | 未定义 | 有外部消费者时 |
| `toItemPayload` 空 hash 死代码 | 可删或 `@deprecated` | 顺手清理 |
| `.thinking-advisor/状态.md` 等并行文件 | 以 `项目.md` + sessions 为准 | 妨碍使用时归档 |
