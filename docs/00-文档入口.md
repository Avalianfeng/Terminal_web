## 防臃肿（写文档时）

1. **先问权威落点**：契约 → `08`；下一刀 → `09`；产品句 → `06`；勿在第四处复制长文。  
2. **过程文档可旧**：`01`–`05`、`07` 保留约束与否决痕迹，标题已标明角色即可，不必每轮「现代化重写」。  
3. **决定要短记**：难逆结构取舍 → **`docs/adr/`**（选了/否了）；契约字段 → `08`；下一刀勾选 → `09`。不要把讨论纪要整段贴进清单。  
4. **清单只保留仍有约束力的项**：完成则勾选；否决压成一句进 §4；过期 WIP 进中枢，不堆进 `docs/`。
