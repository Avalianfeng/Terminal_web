# 站点身份手测（SitePrincipal）

> 对应 [`adr/0010-site-principal.md`](adr/0010-site-principal.md)。终端 `edit` 路径仍见 [`11`](11-终端edit手测清单.md)。

前置：`npm run owner:password` 写入 `.env.local`，重启 `npm run dev`。

## local-dev

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 不 login，`whoami` | 档案人物名 + 角色 `owner` + 会话 `implicit-local-dev` |
| 2 | `help` | 有 `edit`；无 `login`/`logout` |
| 3 | Tab 补全 | 无 `login`；有 `edit` |
| 4 | `login` | 掩码提示；成功后 `via` 可为 `cookie` |
| 5 | `login secret`（口令当参数） | 拒绝；history 不应出现明文口令 |
| 6 | `logout` | 清 cookie；本机仍 implicit owner |

## 模拟 production（访客）

将 `NODE_ENV=production` 跑 `next start`（须已 `owner:password` + `ARCHIVE_SESSION_SECRET`）。

| # | 步骤 | 期望 |
|---|------|------|
| 7 | 未登录 `whoami` | 角色 `visitor`，会话 `none` |
| 8 | `help` / Tab | 无 `edit`、无 `login` |
| 9 | 手打 `edit foo` | 需要主人会话 |
| 10 | `music import` / 点播网易流 | 403 / 需要主人 |
| 11 | `login` 正确口令 | `whoami` = owner / cookie；`edit` 出现；BFF 可用（若有 `.netease-cookie`） |
| 12 | 错误口令多次 | 稍后 429 |

## Agent 写

`npm run smoke:write-api` 仍全绿（Bearer，与 session 无关）。
