## 1. 版本分界

| 阶段 | 一句话 | 结论 |
|------|--------|------|
| **V0** | 证明：人物档案可用**终端**探索，正文可在**纸面**阅读 | **已结束** |
| **v1.0** | 从「能用的控制台」变成「可被人或 Agent 认真使用的档案站」 | **当前进入** |
| **v1.x / v2** | 多媒体对象、更完整编辑 UI、更深 AI 工作流 | 大图景，不塞进最小 v1.0 |

**V0 已交付（不再当主线扩）**

- Dual Phase：浅色工作场 + 深色终端壳 + 外区阅读 `main`/`rail`
- xterm 档位 1、Tab、批量 `open` / `find` / `status`、palette、fullscreen
- 内容形态以 Markdown / JSON **纯文本**为主；命令 runtime 自有（不嵌 Linux）

**V0 明确不再优先**

- 轻量/完整进场叙事（等内容与机器接口都站稳再做）
- 再堆 `/themes` 皮肤、外区动效库、真窗管

## 2. 产品句（v1 起）

**cylf.me 是策月帘风的个人数字档案：终端是探索器，纸面是阅读器，HTTP 发现与读是给 Agent 的正式入口；目标是可扩展的富读中枢（外源后挂），不是先做成写编排中心。**

- 对人：长文与世界观材料要在站内有好的呈现，而不是「markdown 预览凑合看」。
- 对 Agent：服务器在线即可发现与读取（约定范围内）——**不依赖本机 Cursor CLI**；鉴权写已按最小闭环落地（见 §4/§7），复杂权限后置。
- 对以后：外源（如 GitHub）、其它 kind、音乐/图/视频是档案/发现的扩展，不是把站点改成媒体站首页。
- 发现层对象模型（设计锁定）：[`08-发现层对象模型.md`](08-发现层对象模型.md)。

## 3. 大图景（写入计划，但不等于现在全做）

### 3.1 呈现与对象

| 方向 | 含义 | 大致落点 |
|------|------|----------|
| 纯文本深化 | 自我探索 / 世界观长文的纸面与目录可读性 | **v1.0 核心** |
| 图片 | 附图、图注、与文档挂接 | v1.x |
| 音乐 | 可播对象或文档内嵌音频 | v1.x |
| 视频 | 外链或自托管片段 | v1.x / v2 |
| 外站关联 | 其他自有站点 / 项目入口作为档案边 | v1.x |
| 进场叙事 | 访客第一次理解「进了什么世界」 | 文本与 API 稳后 |

### 3.2 权限与编辑

| 方向 | 含义 | 大致落点 |
|------|------|----------|
| 身份 | 访客只读；所有者（及授权 Agent）可写 | **已做**（08-07：Bearer token + scope） |
| 多入口编辑 | 终端命令 / 阅读面板 / API 同一写路径 | API 与终端 `edit` 已同一真相源（`content-write.ts`）；完整编辑 UI 在 v1.x |
| 安全模型 | token / session、范围权限、审计；禁止「能改无鉴权」 | HTTP：token + scope + If-Match **已做**；UI 写与公网姿态分轨见 **[`adr/0007`](adr/0007-security-deployment-posture.md)**；审计 / session 留 v1.x |

### 3.3 AI 获取与深层操作

| 方向 | 含义 | 大致落点 |
|------|------|----------|
| **机器可读拉取** | 开放约定接口：索引、单篇正文、元数据 | **v1.0 必做（B 已完成）** |
| **统一发现对象** | 富读中枢：统一条目；首版仅 document | **已落地**（08 §5 契约形状 + `/api/v1/items` 路由层） |
| **安全写回** | Agent 经鉴权创建/更新档案对象（先文本） | **已完成（08-07 最小闭环）**；完整权限 / 审计 → v1.x |
| 站内 AI 深操作 | 对话式发掘、批注、多文推理 UI | v1.x / v2 |
| Cursor CLI | 仅作开发者可选工具；**不是**生产依赖 | 始终非必须 |

**AI 入口原则（钉死）**

1. **Server-online = operable**：Agent 只依赖站点（或同机对外服务）在线与凭证，不依赖某台电脑开着 Cursor。  
2. **读与写分离**：公开读可以宽；写必须鉴权 + 范围（例如只许 `thoughts/`）。  
3. **API 是一等公民**：终端与纸面是人的视图；Agent 不爬 HTML，走正式 JSON/Markdown 接口。  
4. **编辑经同一真相源**：人 UI 与 Agent 写的是同一内容层，避免「CLI 改盘、站点另一份」双源。

### 4.2 明确不做（当前阶段仍成立）

- 音乐 / 视频播放器、图库产品化
- 完整站内富文本编辑器、多入口精修 UI
- 进场 `whoami` 剧本、第二套非终端首页
- 「无鉴权的方便写入」、把 Cursor CLI 写成唯一编辑方式
- 多人档案、复杂 RBAC；把编排中枢当眼前主线
- 首版发现对象塞进 person / timeline / 外源实体（见 `08`）

### 4.3 成功标准

- 冷访客：能用终端找到并读完一篇世界观/自我探索长文，纸面不别扭。（A 已覆盖）  
- Agent（现行）：仅凭「服务在线 + `08`」能发现统一条目并拉取正文。（B + E 已覆盖）  
- Agent（目标）：发现层以统一 `document` 条目扫读并跟进正文（`08`；**已落地，可按此验收**）。  
- 写验收（08-07）：`curl PUT`（无 token 401 / scope 不足 403 / If-Match 不匹配 409 / 成功 201·200）与 `DELETE`（200 / 404）全路径通过；`GET` 详情回读 `hash` 一致。
