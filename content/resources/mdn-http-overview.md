## 为什么收藏

本站发现层契约（`08`）本身就是 HTTP JSON；这篇作为「读外站 + 本地备注」的最小样本。

## 要点

- HTTP 是无状态请求/响应协议。
- 资源用 URL 标识；方法（GET/PUT/…）表达意图。
- 与档案站关系：Agent 读我们，我们读 MDN——都是链接 + 本地解读。
